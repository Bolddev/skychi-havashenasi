# 🌤️ اسکای‌چی (SkyChi)

**دستیار هوشمند تصمیم‌گیری هوای بعدازظهر**

> بگو امروز کِی و چی بپوشم، نه اینکه دما چنده.

## درباره

اسکای‌چی یک اپلیکیشن وب پیشرفته (PWA) است که به جای نمایش داده‌های خام هواشناسی، **تصمیم‌های شخصی‌سازی‌شده** ارائه می‌دهد. این اپ برای ساکنان **قرچک، استان تهران** طراحی شده و از API رایگان [Open-Meteo](https://open-meteo.com) استفاده می‌کند.

## ✨ قابلیت‌ها

- 🎯 **تصمیم‌گیری هوشمند**: پیشنهاد بهترین زمان خروج بر اساس آستانه‌های شخصی
- 🌡️ **هشدار شوک دمایی**: تشخیص افت ناگهانی دما نسبت به دیروز
- ☀️ **پنجره طلایی**: پیدا کردن بهترین بازه زمانی برای بیرون رفتن
- 👕 **توصیه پوشش و تجهیزات**: بر اساس شرایط واقعی و وسایل موجود
- 📊 **امتیاز فعالیت‌ها**: بررسی مناسب بودن هر فعالیت (پیک‌نیک، پیاده‌روی، عکاسی و...)
- 🚗 **برنامه‌ریز کارواش**: تصمیم‌گیری هوشمند برای شستن ماشین
- 👥 **مقایسه پروفایل‌ها**: پیدا کردن زمان مشترک با دوستان
- 🌙 **آسمان شب**: اطلاعات فاز ماه و ستاره‌بینی
- 📡 **آفلاین‌پذیر**: کار کردن بدون اینترنت پس از اولین بارگذاری
- 📱 **نصب‌پذیر**: PWA با قابلیت نصب روی موبایل

## 🚀 نصب و اجرا

### پیش‌نیازها

- Node.js 18+
- npm یا yarn

### نصب

```bash
# کلون کردن مخزن
git clone https://github.com/yourusername/skychi.git
cd skychi

# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت نسخه production
npm run build
```

## 📁 ساختار پروژه

```
skychi/
├── src/
│   ├── components/       # کامپوننت‌های React
│   │   ├── ui/          # کامپوننت‌های پایه (Button, Card, Modal...)
│   │   ├── layout/      # Header, BottomNav, AppShell
│   │   ├── widgets/     # ویجت‌های صفحه اصلی
│   │   ├── modals/      # مودال‌ها
│   │   └── states/      # حالت‌های مرزی (آفلاین، خطا...)
│   ├── screens/         # صفحات اصلی
│   ├── engine/          # موتور قواعد (منطق اصلی)
│   ├── data/            # لایه داده (API, cache, normalizer)
│   ├── types/           # تایپ‌های TypeScript
│   ├── hooks/           # هوک‌های سفارشی
│   ├── utils/           # توابع کمکی
│   ├── pwa/             # فایل‌های PWA
│   └── styles/          # استایل‌ها و توکن‌ها
├── public/              # فایل‌های استاتیک
│   ├── manifest.json    # PWA manifest
│   ├── sw.js            # Service Worker
│   └── icons/           # آیکون‌ها
└── docs/                # مستندات
```

## 🧠 معماری

اسکای‌چی از معماری سه لایه‌ای استفاده می‌کند:

1. **لایه داده (Data Layer)**: دریافت داده از Open-Meteo، نرمال‌سازی، کش
2. **لایه منطق (Engine Layer)**: موتور قواعد، محاسبه ریسک، تصمیم‌گیری
3. **لایه ارائه (UI Layer)**: کامپوننت‌ها، ویجت‌ها، صفحات

برای جزئیات بیشتر، [ARCHITECTURE.md](./docs/ARCHITECTURE.md) را ببینید.

## 🔧 تکنولوژی‌ها

- **React 18** + **TypeScript**
- **Vite** برای build
- **Tailwind CSS** برای استایل
- **Zustand** برای مدیریت state
- **Open-Meteo API** برای داده‌های هواشناسی
- **PWA** با Service Worker

## 📱 PWA

اسکای‌چی یک Progressive Web App کامل است:

- ✅ قابل نصب روی موبایل و دسکتاپ
- ✅ کار کردن آفلاین
- ✅ آیکون روی صفحه اصلی
- ✅ به‌روزرسانی خودکار
